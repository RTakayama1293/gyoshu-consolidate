# 業種別企業リスト統合（gyoshu-consolidate）

貨物営業部向け。業種別の企業CSV（ファイル名 = `大分類_小分類.csv`）を
1つの統合リストに集約する Claude Code on the Web 用リポジトリ。

## セットアップ手順

1. このリポジトリをGitHubにプッシュ
2. `data/raw/` に **53個のCSV** を配置（ファイル名は `大分類_小分類.csv` 形式のまま）
   - サンプルとして `漁業_水産養殖.csv` と `製造_業務用機械製造.csv` を同梱済み
3. CCW（https://claude.ai/code）でこのリポジトリを開く
4. 「src/consolidate.py を実行して」と指示

## 出力

`outputs/統合_業種別企業リスト.csv`（.xlsx も同時生成）

| 列 | 内容 | 備考 |
|----|------|------|
| 大分類 | ファイル名由来 | |
| 小分類 | ファイル名由来 | |
| 社名 | 会社名 | |
| 地方 | 都道府県から自動判定 | 8地方区分 |
| 都道府県 | 住所から自動判定 | |
| 郵便番号 | | |
| 住所 | | |
| 代表者名 | 代表者の氏名 | **欠損多** |
| 代表電話 | 電話番号 | **欠損多** |
| 法人番号 | | 重複排除キー |

## 注意
- 代表者名・代表電話は元データ（Sansanエクスポート）でほぼ空欄。推定では埋めない
- 大分類・小分類はファイル名を正とする

## ローカル実行

```bash
pip install -r requirements.txt
python src/consolidate.py
```
